# Oh My Friend (오마이프렌드) 🎮⛏️

> **macOS Desktop Companion in Minecraft Style**  
> 맥 화면 위를 스스로 돌아다니고, 창문에 걸터앉거나, 마우스 커서를 바라보고, Dock을 툭툭 건드리는 마인크래프트 3D 복셀 친구!

---

## 📸 Overview

- **3D 마인크래프트 복셀 캐릭터**: 머리, 몸통, 팔, 다리가 분리된 관절 피벗 구조로 자연스러운 걷기, 숨쉬기, 걸터앉기, 블록 캐기(펀치), 낙하, 버둥거리기 모션을 보여줍니다.
- **화면 및 창문 인식**: 열려 있는 사파리, 터미널, 크롬 등 다른 앱 윈도우의 상단 타이틀바와 macOS 하단/측면 Dock을 발판 플랫폼으로 인식합니다.
- **커서 시선 추적**: 마우스 커서의 움직임을 실시간으로 따라가며 고개를 갸우뚱거리며 쳐다봅니다.
- **물리 엔진**: 창문이 닫히거나 치워지면 으악! 소리와 함께 중력으로 떨어지며, 마우스로 들어 올려 던질 수도 있습니다.
- **커스텀 스킨 & 온라인 갤러리**:
  - **인기 스킨 갤러리**: 테크노블레이드, 노치, 젭, 드림, 크리퍼, 아이언맨, 스파이더맨 등 인기 스킨 원클릭 다운로드 & 착용
  - **플레이어 닉네임 검색**: 전 세계 정품 마인크래프트 유저의 닉네임(예: `Technoblade`, `Notch`)을 입력해 실시간 스킨 다운로드
  - **웹 사이트 & 직링크**: NameMC, The Skindex 바로가기 및 PNG 웹 주소로 즉시 다운로드
  - **드래그 앤 드롭**: 인터넷에서 다운로드한 64×64 PNG 파일을 캐릭터에 던져 넣으면 바로 변신

## 💻 요구 사항 (Prerequisites)

- **운영체제**: macOS 13.0 (Ventura) 이상 (Apple Silicon M1/M2/M3/M4 및 Intel Mac 지원)
- **개발 도구**: Xcode Command Line Tools 및 Swift 5.9+
  - 아직 설치되어 있지 않다면 터미널에서 다음 명령어로 설치할 수 있습니다:
    ```bash
    xcode-select --install
    ```

## 🚀 빠른 시작 (Quick Start)

### 1. 저장소 클론 (Clone)

터미널을 열고 저장소를 클론합니다:

```bash
git clone https://github.com/allbegray/oh-my-friend.git
cd oh-my-friend
```

### 2. 빌드 및 즉시 실행 (Build & Run)

원클릭 스크립트로 릴리스 빌드와 실행을 한 번에 진행할 수 있습니다:

```bash
./scripts/run.sh
```
*(첫 빌드 시 Swift 패키지 컴파일에 약 30~40초 정도 소요될 수 있습니다.)*

---

## 📦 시스템에 설치하기 (Installation)

맥의 응용 프로그램 폴더(`/Applications`)에 정식 앱으로 설치하여 Spotlight(Cmd + Space)나 Launchpad에서 언제든지 켤 수 있도록 설정합니다.

```bash
./scripts/install.sh
```

설치가 완료되면:
1. `Cmd + Space`로 Spotlight를 열고 **Oh My Friend**를 입력하여 실행할 수 있습니다.
2. 상단 macOS 메뉴바에 귀여운 **8-bit 스티브 얼굴 아이콘**이 나타납니다.

## 🎮 조작 방법 & 상호작용 (How to Play)

| 동작 | 설명 |
| :--- | :--- |
| 👀 **시선 따라가기** | 마우스 커서를 움직이면 캐릭터가 고개를 돌려 커서를 빤히 응시합니다. |
| ✋ **잡아서 던지기** | 캐릭터를 마우스 좌클릭으로 잡고 들어올리면 공중에서 팔다리를 허우적거리며, 원하는 방향으로 던지면 관성으로 날아갑니다. |
| 🪟 **창문 타기 & 걸터앉기** | 열려 있는 창문 위를 아장아장 걷다가, 창문 모서리에 다다르면 다리를 앞으로 뻗고 걸터앉아 다리를 살랑살랑 흔듭니다. 창을 치우면 아래로 떨어집니다! |
| ⛵ **Dock 건드리기** | Dock 위를 산책하다가 멈춰 서서 아래를 빤히 쳐다보며 마인크래프트 특유의 팔 휘두르기(펀치) 모션으로 Dock 아이콘을 툭툭 칩니다. |
| 🌐 **스킨 갤러리 & 다운로더** | 상단 메뉴바 아이콘 클릭 후 **"🌐 스킨 갤러리 & 다운로더... (Cmd + G)"**를 열면 인기 스킨 카탈로그 브라우징, 닉네임 검색, 스킨 직링크 다운로드를 지원합니다. |
| 👕 **스킨 변경** | 기본 스킨(Steve / Alex / Zombie) 선택, 갤러리에서 다운로드한 스킨 착용, 또는 64×64 PNG 스킨 파일을 캐릭터 창에 **드래그 앤 드롭**하세요. |
| 🎭 **행동 모드** | 메뉴바에서 **자유 배회(자율 AI)**, **커서 따라오기**, **멍때리기(Chill)** 중 원하는 모드를 선택할 수 있습니다. |
| 📏 **크기 조절** | 작게(70%), 보통(100%), 크게(150%) 중 원하는 크기로 조절 가능합니다. |
| 🦘 **폴짝 뛰기 (Jump)** | 메뉴바에서 점프를 시키거나, 캐릭터를 바닥으로 소환(Reset)할 수 있습니다. |
| 🚪 **종료** | 메뉴바 아이콘 클릭 후 **종료 (Quit)**를 누르면 완전히 종료됩니다. |

## 🛠️ 수동 빌드 (Manual Build)

스크립트 없이 직접 빌드하고 싶다면:

```bash
# 디버그 빌드
swift build

# 릴리스 빌드
swift build -c release

# 앱 번들 생성
./scripts/build_app.sh
```

---

## 🗑️ 삭제 방법 (Uninstall)

설치된 앱을 제거하려면 응용 프로그램 폴더에서 앱을 휴지통으로 이동하면 됩니다:

```bash
rm -rf /Applications/OhMyFriend.app
# 또는 ~/Applications/OhMyFriend.app
```
