# Oh My Friend: 마인크래프트 스타일의 macOS 데스크톱 컴패니언 🎮⛏️

> 맥 화면 위를 스스로 돌아다니고, 창문에 걸터앉거나, 마우스 커서를 바라보고, Dock을 툭툭 건드리는 3D 복셀 친구!

---

## 시작하기

### 1. 요구 사항
- **운영체제**: macOS 13.0 (Ventura) 이상 (Apple Silicon M1/M2/M3/M4 및 Intel Mac 지원)
- **개발 도구**: Xcode Command Line Tools 및 Swift 5.7+
  - 미설치 시 터미널에서 아래 명령어로 설치:
    ```bash
    xcode-select --install
    ```

### 2. 저장소 클론 및 빠른 실행
```bash
git clone https://github.com/allbegray/oh-my-friend.git
cd oh-my-friend

# 빌드 및 즉시 실행
./scripts/run.sh
```

### 3. macOS 시스템에 설치하기
맥의 응용 프로그램 폴더(`/Applications`)에 정식 앱으로 등록하여 Spotlight(`Cmd + Space`)로 실행할 수 있습니다:
```bash
./scripts/install.sh
```

## 주요 기능

### 1. 3D 마인크래프트 복셀 캐릭터 & 자율 AI
- **표준 복셀 모델링**: 머리(8×8×8), 몸통(8×12×4), 양팔(4×12×4), 양다리(4×12×4)의 관절 피벗 계층 구조 기반 자연스러운 움직임.
- **실시간 커서 시선 추적**: 화면 상의 마우스 커서 위치를 실시간으로 추적하여 고개를 상하좌우로 갸우뚱거리며 응시.
- **스마트한 창문 & Dock 플랫폼 인식**: `CGWindowList`를 통해 열려 있는 다른 앱 창문의 상단 타이틀바와 macOS Dock을 발판 삼아 아장아장 걷고, 창문 모서리에 걸터앉아 다리를 살랑살랑 흔듦.
- **물리 엔진 & 낙하**: 창문이 닫히거나 치워지면 중력으로 떨어지며, 마우스로 캐릭터를 잡아올려 던질 수 있는 관성 물리 적용.
- **Dock 아이콘 툭툭 치기**: Dock 위에서 마인크래프트 펀치/채굴 모션으로 아이콘을 콕콕 건드림.

### 2. 온라인 스킨 갤러리 & 다운로더 (`Cmd + G`)
- **인기 스킨 갤러리**: 테크노블레이드, 노치, 젭, 드림, 크리퍼, 아이언맨, 스파이더맨 등 인기 스킨 원클릭 다운로드 & 착용.
- **플레이어 닉네임 검색**: 마인크래프트 정품 계정 닉네임을 검색하여 Mojang / Minotar API를 통해 실시간으로 64×64 PNG 스킨 및 전신 렌더를 받아 즉시 착용.
- **웹 사이트 & 직링크 다운로드**: NameMC, The Skindex 바로가기 지원 및 스킨 이미지 직링크(PNG URL) 다운로드.
- **드래그 앤 드롭 지원**: 웹이나 로컬에서 다운로드한 64×64 PNG 파일을 캐릭터 창에 끌어다 놓으면 즉시 스킨 변경.
- **오프라인 내 보관함**: 다운로드한 스킨을 `~/Library/Application Support/OhMyFriend/Skins/`에 자동 보관하여 언제든지 재착용 가능.

### 3. 네이티브 상단 메뉴바 & 컨텍스트 메뉴
- 상단 메뉴바의 8-bit 스티브 얼굴 아이콘 및 실시간 행동 상태 표시.
- 기본 스킨 빠른 선택(Steve, Alex, Zombie), 행동 모드(자유 배회, 커서 따라오기, 멍때리기), 캐릭터 크기 조절(70%, 100%, 150%) 지원.

| 조작 | 설명 |
