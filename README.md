# Oh My Friend: 마인크래프트 스타일의 macOS 데스크톱 컴패니언 🎮⛏️

> 맥 화면 위를 스스로 돌아다니고, 창문에 걸터앉거나, 마우스 커서를 바라보고, Dock을 툭툭 건드리는 3D 복셀 친구!

---

## 시작하기

- **요구 사항**: macOS 13.0 이상, Xcode Command Line Tools(Swift 5.7+)
  ```bash
  xcode-select --install
  ```
- **바로 실행**: [GitHub Releases](https://github.com/allbegray/oh-my-friend/releases)에서 `OhMyFriend-macOS-arm64.zip` → `/Applications` 이동 → 최초 1회 `xattr -cr /Applications/OhMyFriend.app` → 실행
- **소스에서 실행**:
  ```bash
  git clone https://github.com/allbegray/oh-my-friend.git && cd oh-my-friend
  ./scripts/run.sh      # 빌드 및 즉시 실행
  ./scripts/install.sh  # /Applications에 설치
  ```

## 주요 기능

### 코어 & 캐릭터
- **3D 복셀 + 스킨 2차 레이어**: 64×64 스킨의 모자/외투/소매/바지 오버레이 완벽 지원.
- **자율 AI**: 커서 시선 추적, 다중 모니터 이동, 창문·Dock·메뉴바 발판, 걸터앉기·낮잠·낙하 물리.
- **기본 액션**: 공중제비(더블클릭), 인사, 하트, 쉬프트 댄스, 사다리 등반, 타이핑 응원, 알림 구박, 낚시, 겉날개 활공, 방패 가드.
- **스킨 갤러리 (`Cmd + G`)**: 인기 스킨·닉네임 검색(Mojang/Minotar)·Laby.net/NameMC·드래그 앤 드롭·로컬 보관함.

### 몹 & 전투 (메뉴: ✨ 재미있는 모션 실행)
- **클래식**: 크리퍼(무기별 처치), 엔더맨(눈싸움), 스켈레톤(활·햇빛 발화), 슬라임(분열), 마녀, 거미, 가스트(화염탄 테니스), 좀비 공성전, 팬텀.
- **펫 & 동료**: 늑대·고양이·앵무새·돼지·말(승마)·아홀로틀·양·판다·닭·무쉬룸 + 친구 최대 2기.
- **시스템**: XP·인챈트·양조·주민 거래·발전 과제 16종·낮밤 사이클·날씨(비·뇌우).

### 농장 & 생활
- **밭작물**: 밀·감자(구운감자·썩은감자)·수박(슬라이스·반짝임 양조)·호박(엔더맨 면역·파이)·사과나무(낙과·도끼 벌목)·빵 굽기(밀 3개+캠프파이어).
- **거점**: 캠프파이어(휴식)·주크박스(리듬 댄스)·보물상자·지옥문·양궁 과녁·케이크·벌집·TNT 폭파.

### 꾸미기 & 이벤트 (메뉴: 🎉 추가 모션 9~17차)
- 야생 동물(토끼·북극곰·개구리·거북), 네더 몹(위더·블레이즈·익사자·브리즈), 물(오징어·복어·기포·스펀지·무지개), 소셜(포옹·악수·보물지도·기념사진), 레드스톤(레버·음표·액자·배너·트립와이어), 겨울(눈싸움·별똥별), 사막(낙타·라마·행상인·사원), 엔드(후렴과·셜커·드래곤 알), 이벤트(습격·피리·활공 링·몹 머리).

## 조작 방법 요약

| 조작 | 설명 |
| :--- | :--- |
| 👀 **쳐다보기 & 인사** | 커서를 바라보고, 머리 근처에 닿으면 손을 흔듭니다. (`Cmd + W`) |
| 🤸‍♂️ **더블 클릭** | 360도 공중제비! (`Cmd + B`) |
| ❤️ **클릭** | 하트 + 쉬프트 댄스. (`Cmd + T`) |
| ✋ **잡아서 던지기** | 좌클릭 드래그로 들어올려 던집니다. |
| 🪜 **사다리** | 창문 안에 놓으면 사다리로 올라가고, 메뉴에서 내려갑니다. (`Cmd + L`) |
| 🗡️ **아이템·펫·몹** | 메뉴바 ➜ 손에 아이템·펫 동반자·✨ 재미있는 모션 실행에서 소환. |
| 🎉 **추가 모션** | 메뉴바 ➜ 🎉 추가 모션 9~17차에서 차수별 44종 실행. |
| 🪑 **메뉴바 앉기** | ✨ 메뉴 또는 화면 상단에 놓기. (`Cmd + M`) |
| 💥 **전투** | 크리퍼(`Cmd + K`)·엔더맨(`Cmd + E`) 소환 후 무기/방패로 처치. |
| 🎣 **낚시** | 모서리에 앉아 낚싯대 던지기. (`Cmd + F`) |
| 🌱 **농사** | ✨/🎉 메뉴에서 심고 자라면 클릭 수확. |
| 💤 **낮잠** | 45초 방치 시 3D 침대 수면, 움직이면 기상. (`Cmd + Z`) |
| 🌐 **스킨** | 갤러리(`Cmd + G`) 또는 PNG 드래그 앤 드롭. |
| 📏 **크기·소리** | 9단계 프리셋 + 직접 입력(`Cmd + S`), 효과음 토글. |
| 🚪 **종료** | 메뉴바 아이콘 클릭 ➜ 종료. |
