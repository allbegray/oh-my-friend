# Oh My Friend: 마인크래프트 스타일의 macOS 데스크톱 컴패니언 🎮⛏️

> 맥 화면 위를 스스로 돌아다니고, 창문에 걸터앉거나, 마우스 커서를 바라보고, Dock을 툭툭 건드리는 3D 복셀 친구!

---

## 시작하기

- **요구 사항**: macOS 13.0 이상, Xcode Command Line Tools(Swift 5.7+)
  ```bash
  xcode-select --install
  ```

- **설치 (권장 · DMG)**: [GitHub Releases](https://github.com/allbegray/oh-my-friend/releases/latest)에서 `OhMyFriend-macOS-arm64.dmg` 내려받기 → 이미지 열기 → **OhMyFriend.app 을 Applications 로 드래그**.
  - 처음 실행할 때 *"확인되지 않은 개발자"* 경고가 뜨면 **앱을 Control-클릭(우클릭) → 열기 → 열기**를 한 번만 해주면 이후로는 뜨지 않습니다.
  - 그 경고조차 피하려면 터미널에서 한 줄:
    ```bash
    xattr -cr /Applications/OhMyFriend.app
    ```
- **설치 (ZIP)**: `OhMyFriend-macOS-arm64.zip` 을 받아 압축을 풀고 `OhMyFriend.app` 을 Applications 로 이동. 최초 1회 위와 동일하게 `xattr -cr` 또는 우클릭 → 열기.
  - 이 ZIP 은 앱 내 **자동 업데이트(`Cmd + U`)** 가 내려받는 형식이라 계속 함께 배포됩니다.

> 앱은 **Developer ID 서명 + Hardened Runtime** 상태로 배포되며, 인증서가 없는 로컬 빌드는 동일한 구성의 **ad-hoc 서명**으로 만들어집니다. Apple 공증(notarization)은 Developer ID 인증서가 있는 환경에서 자동으로 수행됩니다 — 자세한 내용은 `SECURITY.md` 참고.

- **소스에서 실행**:
  ```bash
  git clone https://github.com/allbegray/oh-my-friend.git && cd oh-my-friend
  ./scripts/run.sh      # 빌드 및 즉시 실행
  ./scripts/build_app.sh   # OhMyFriend.app 생성 (서명 포함)
  ./scripts/make_dmg.sh    # 드래그 설치용 DMG 생성
  ./scripts/install.sh  # /Applications에 설치
  ```

## 주요 기능

### 코어 & 캐릭터
- **3D 복셀 + 스킨 2차 레이어**: 64×64 스킨의 모자/외투/소매/바지 오버레이 완벽 지원.
- **자율 AI**: 커서 시선 추적, 다중 모니터 이동, 창문·Dock·메뉴바 발판, 걸터앉기·낮잠·낙하 물리.
- **기본 액션**: 공중제비(더블클릭), 인사, 하트, 쉬프트 댄스, 사다리 등반, 타이핑 응원, 알림 구박, 낚시, 겉날개 활공, 방패 가드.
- **감정 표현 8종**: 박수 갈채·빙글빙글 회전·기지개 스트레칭·팔벌려뛰기·제자리 달리기·가부좌 명상·정중한 인사·물구나무서기. 자유 배회 중에도 스스로 골라 선보입니다(자율 판단의 12%).
- **스킨 갤러리 (`Cmd + G`)**: 인기 스킨·닉네임 검색(Mojang/Minotar)·Laby.net/NameMC·드래그 앤 드롭·로컬 보관함.
- **자동 업데이트 (`Cmd + U`)**: GitHub Releases 연동 무중단 인플레이스 다운로드 및 자동 재실행.

### 외형 꾸미기 (메뉴: 👕 외형 꾸미기)
- **기본 스킨 & 색조 필터**: 내장 스킨 3종 + 6가지 색조/채도/명도 필터.
- **손 장비 & 외형**: 다이아몬드 검/도끼/곡괭이/삼지창 등 15종 손 아이템, 🛡️ 왼손 방패, 🪽 겉날개 착용, 🔮 무기 인챈트 광택 토글.
- **캐릭터 크기**: 9단계 배율 프리셋 + 수치 직접 입력 지원.

### 몹 & 전투 (메뉴: ✨ 재미있는 모션 실행)
- **전투 AI**:
  - **스켈레톤**: 화살 피격/방어 시 검 발도 + 분노 돌격(Aggro) 추격전, 햇빛 그늘 순찰 AI.
  - **크리퍼**: 4족 및 2족 직립 보행 지원, 무기별 처치 및 충돌 밀침.
  - **적대적 몹**: 엔더맨(눈싸움), 슬라임(접근 시 검으로 능동 돌격 사냥), 마녀, 거미, 가스트(화염탄 테니스), 좀비 공성전, 팬텀.
- **펫 & 동료**: 늑대·고양이·앵무새·돼지·말(승마)·아홀로틀·양·닭·무쉬룸 + 친구 최대 2기.
- **시스템**: XP·인챈트·양조·주민 거래·발전 과제 16종·낮밤 사이클·날씨(비·뇌우, 기본 OFF).

### 농장 & 인터랙션
- **밭작물 (자율 수확)**: 밀·감자·수박·호박·사과나무(성숙 시 캐릭터가 다가가 도구로 수확).
- **거점 상호작용**:
  - 🎯 **과녁**: 캐릭터가 직접 활을 겨눠 사격하고 명중 시 과녁이 흔들림.
  - 🎂 **케이크**: 캐릭터가 다가가 한 입 베어먹고 포만감 표현.
  - 📦 **보물상자**: 캐릭터가 다가가 손 뻗어 열고 전리품 방출.
  - 캠프파이어(휴식)·주크박스(리듬 댄스)·지옥문·벌집·TNT 폭파.

## 조작 방법 요약

| 조작 | 단축키 / 방법 | 설명 |
| :--- | :--- | :--- |
| 👀 **쳐다보기 & 인사** | `Cmd + W` | 커서를 바라보고 머리 근처에 닿으면 손을 흔듭니다. |
| 🤸‍♂️ **더블 클릭** | `Cmd + B` | 360도 공중제비 점프! |
| ❤️ **클릭** | `Cmd + T` | 하트 방출 + 쉬프트 댄스. |
| ✋ **잡아서 던지기** | 마우스 좌클릭 드래그 | 공중에 들어올려 물리 관성으로 던집니다. |
| 🪜 **사다리 등반** | `Cmd + L` | 창문 안에 놓으면 등반하고, 메뉴에서 내려갑니다. |
| 👕 **외형 꾸미기** | 메뉴바 ➜ 👕 외형 꾸미기 | 스킨, 색조, 손 아이템, 방패, 겉날개, 인챈트 광택. |
| 🐾 **펫 동반자** | 메뉴바 ➜ 🐾 펫 동반자 | 늑대, 고양이, 앵무새, 말, 돼지 등 펫 소환 및 먹이 주기. |
| ✨ **재미있는 모션** | 메뉴바 ➜ ✨ 모션 실행 | 몹 소환, 전투, 농작물 심기, 거점 오브젝트 소환, 감정 표현 8종. |
| 💥 **몬스터 소환** | `Cmd + K` / `Cmd + E` | 크리퍼, 엔더맨 즉시 소환 후 전투. |
| 🎣 **낚시** | `Cmd + F` | 창문이나 화면 모서리에 앉아 낚싯대 던지기. |
| 💤 **낮잠** | `Cmd + Z` | 45초 방치 시 3D 침대 수면, 움직이면 기상. |
| 🌐 **스킨 갤러리** | `Cmd + G` | 온라인 스킨 검색, 인기 스킨, PNG 드롭. |
| 🔄 **업데이트 확인** | `Cmd + U` | GitHub 최신 릴리스 확인 및 자동 인플레이스 업데이트. |
| ⚙️ **설정** | 메뉴바 ➜ ⚙️ 설정 | 낮밤, 날씨(기본 OFF), 밝기(6단계), 3D 광원, CPU 파워. |
| 🚪 **종료** | 메뉴바 아이콘 클릭 ➜ 종료 | 앱 안전 종료. |
